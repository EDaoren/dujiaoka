# EDaoren 模板

一个现代化、美观的独角数卡模板

## 设计特点

### 视觉设计
- **渐变背景**: 采用紫色渐变背景 (#667eea → #764ba2)，营造现代科技感
- **毛玻璃效果**: 使用 backdrop-filter 实现半透明毛玻璃效果
- **圆角设计**: 所有卡片和按钮采用大圆角设计，更加柔和美观
- **阴影层次**: 多层次阴影效果，增强视觉深度

### 交互体验
- **悬停动画**: 卡片悬停时上浮并放大，图片缩放效果
- **渐变按钮**: 所有按钮采用渐变色，悬停时反转渐变方向
- **平滑过渡**: 所有交互都有流畅的过渡动画
- **入场动画**: 商品卡片依次淡入上浮，增强视觉吸引力

### 色彩方案
- **主色调**: 紫色渐变 (#667eea, #764ba2)
- **成功色**: 绿色渐变 (#11998e, #38ef7d)
- **警告色**: 粉红渐变 (#f093fb, #f5576c)
- **强调色**: 金色 (#ffd700)

### 响应式设计
- 完全响应式布局，适配各种屏幕尺寸
- 移动端优化的导航栏和卡片布局
- 触摸友好的按钮和交互元素

## 技术特性

- 基于 Bootstrap 5 框架
- 使用 CSS3 现代特性（渐变、过渡、动画、毛玻璃）
- 保持与原有模板的完全兼容性
- 无需修改任何后端逻辑

## 使用方法

1. 在管理后台选择 "edaoren" 模板
2. 上传合适的商品图片（建议尺寸：800x600px）
3. 配置站点 Logo 和文字 Logo
